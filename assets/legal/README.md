# Image Rights — Card Backgrounds (threeweb_4)

This folder records the usage rights for every **externally sourced** image
used on the site, plus the evidence that was captured when each was obtained
(retrieved 2026-09-27 from Pexels and Wikimedia Commons).

Card background files live in `assets/cards/`; people photos in `assets/people/`. They are resized (1400px max)
JPEG copies; the originals were not modified in any other way.

## 4. `assets/people/jason-derulo.jpg` — "Jason Derulo at MTV EMAs 2018"

| Field | Value |
| --- | --- |
| Used on | "Why I Started This Foundation" (A Message From Jason) section |
| Author | MTV International (still from an MTV UK YouTube video of the MTV EMAs, 2018-11-05) |
| Commons page | https://commons.wikimedia.org/wiki/File:Jason_Derulo.png |
| Source video | https://www.youtube.com/watch?v=WN6zE-wJ2iE (private as of 2026-09-27) |
| Original file SHA-1 | `0360c39141944bbc586fdaaaf1a9a705bfe7a337` (493 x 713) |
| License | **CC BY 3.0** — https://creativecommons.org/licenses/by/3.0/ |
| Attribution required | **Yes** — given in the site footer's "Photo credits" line (title, author, link to source, link to license, and "cropped") |
| Changes made | Cropped to 3:4 (493 x 657); converted PNG to JPEG |

Evidence:
- `jason-derulo_commons-page.wikitext` — raw file-page source, including
  `{{YouTube CC-BY}}` and a completed `{{LicenseReview}}` by Commons reviewer
  Chiyako92 on 2019-03-13, which confirmed the source video was published
  under CC BY
- `jason-derulo_commons-metadata.json` — Commons API license metadata
- `CC-BY-3.0_legalcode.txt` — full CC BY 3.0 legal code

The source video is now private. That doesn't affect the license: CC licenses
are irrevocable for material already released under them (legal code § 7(b)),
and the Commons license review is the standard record that it was released.

**Placing the credit in the footer:** CC BY 3.0 § 4(b) lets the credit "be
implemented in any reasonable manner", and Creative Commons' own attribution
guidance accepts a credits section elsewhere on the page. The credit is a
visible, always-rendered line in the footer (not hidden or collapsed), with all
required elements. This is the ordinary reading of the license, not legal advice.

Notes: the copyright license covers the photograph only. Using Jason
Derulo's likeness on his own foundation's site is a matter for the foundation
and Jason, not the CC license. The page does not suggest MTV endorses the
foundation (CC BY 3.0 § 4(b) no-endorsement clause).

No freely licensed photo of **Mama Luca** exists on Wikimedia Commons or
Openverse, so the "Our Dream" section intentionally has no image.
